# Нефункциональные требования и стек

## Нефункциональные требования

| ID    | Категория          | Требование                                                                              |
|-------|--------------------|-----------------------------------------------------------------------------------------|
| NFR-1 | Безопасность       | Запись на сервер продукта и удаление строк выполняются только с явным подтверждением      |
| NFR-2 | Безопасность       | Имена таблиц и столбцов проверяются и экранируются, значения передаются параметрами SQL   |
| NFR-3 | Безопасность       | Пароли из адресов подключения не выводятся в консоль и журнал                              |
| NFR-4 | Целостность        | Данные применяются одной транзакцией: при ошибке изменения откатываются                   |
| NFR-5 | Надёжность         | Перед записью строится план, по которому видно, что будет добавлено, изменено, удалено     |
| NFR-6 | Производительность | Синхронизация 10 000 строк на таблицу выполняется за секунды, запись идёт пачками по 500   |
| NFR-7 | Переносимость      | Python 3.9+; SQLite без внешних пакетов, для MySQL только драйвер PyMySQL                  |
| NFR-8 | Качество кода      | Покрытие тестами не ниже 80 %, код проходит flake8, black, isort                           |
| NFR-9 | Сопровождаемость   | Добавить новую СУБД можно написанием одного адаптера (SQL-диалект, чтение схемы)          |

## Ограничения

- Переносятся только таблицы, столбцы и строки: индексы, внешние ключи, значения по умолчанию, представления и
  триггеры не переносятся.
- Таблицы без первичного ключа пропускаются.
- Команды изменения схемы (`CREATE/ALTER TABLE`) в MySQL нельзя откатить вместе с данными.
- Базы сравниваются в памяти, модуль рассчитан на учебные и небольшие базы.
- Нет слияния изменений двух разработчиков: направление синхронизации выбирает человек.

## Стек, согласованный командой

| Часть            | Выбор                              |
|------------------|------------------------------------|
| Язык             | Python 3.12                        |
| Локальная БД     | SQLite                             |
| Сервер БД        | MySQL 8 (драйвер PyMySQL)          |
| Веб-панель       | Flask + Jinja2                     |
| Тесты            | pytest, pytest-cov                 |
| Стиль кода       | flake8, black, isort               |
| Хуки             | pre-commit                         |
| CI               | GitHub Actions (в т. ч. сервис MySQL) |
| Контроль версий  | Git, GitHub                        |
