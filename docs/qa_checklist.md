# QA: чек-лист ручного тестирования v0.1.0

Тестировщик: Роговский В.Д. Версия: 0.1.0. Запуск: `python src/seed.py`, затем `python src/app.py`.
Для проверок на настоящем MySQL: `docker compose up -d`, переменная `REMOTE_URL=mysql://root:test@127.0.0.1:3306/test`.
