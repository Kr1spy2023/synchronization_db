## [0.1.0] - 15.11.2026
### Добавлено
- Модуль `db_sync`: синхронизация локальной БД (SQLite) с сервером продукта (MySQL) в обе стороны (`push` и `pull`)
- Построение плана перед записью: добавляемые, изменяемые и удаляемые строки, SQL изменений схемы
- Автоматическое создание недостающих таблиц и столбцов с переводом типов между SQLite и MySQL
- Сравнение строк по первичному ключу с приведением значений к общему виду
- Защита: подтверждение записи на сервер и удаления строк, режим пробного запуска, одна транзакция с откатом при ошибке
- Выбор таблиц (`tables`, `exclude`), команда `status`, журнал синхронизаций в файле
- Командная строка `python -m db_sync status|push|pull`
- Веб-панель «Синхронизация БД» на Flask и Jinja2: сравнение, план, применение, история, просмотр таблиц, защита форм от CSRF
- 86 тестов, покрытие 94 %, отдельная проверка на настоящем MySQL (docker-compose и сервис в CI)
- CI на GitHub Actions: сборка, flake8, black, isort, pytest с покрытием
- Пост-мердж проверка (smoke-тест) после слияния в `main`
- Pre-commit хуки, шаблоны Pull Request и Issue

### Известные ограничения
- Не переносятся индексы, внешние ключи, значения по умолчанию, представления и триггеры
- Таблицы без первичного ключа пропускаются
- Изменения схемы в MySQL нельзя откатить вместе с данными
- BUG-1 (Issue «Значения по умолчанию столбцов не переносятся»): в созданной таблице нет DEFAULT
